## Design Specificity Verdict

Design review: authored. Seat slabs, ranking rows, history entries and champion flood extend the livery system. Weak spots: tournament state on the board is one generic button; the champion screen is quieter than the match-winner screen.

Deterministic scan: detector exit 0, no findings on src/app and src/index.html. Browser injection clean on board, menu, history, next match. Champion screen: 3 findings dark, 1 light, all false positives (low-contrast 1.0:1 on h2 and h3.heading reads the dialog background, text is painted over .flood at 6.05:1; clipped-overflow-container is the .flood child).

Measured, 48 runs (8 views x dark/light x 390x844, 320x568 at 200%, 740x360): 0 contrast pairs under threshold (lowest 5.84:1), 0 targets under 48x48, 0 unnamed controls, 0 sideways scroll, 0 animations under reduced motion.

Visual overlays: headless only; no user-visible overlay.

## Overall Impression

Features work and hold in both themes and at large text. Weak point is orientation during a tournament. Biggest opportunity: one line under the header with the rule and match number.

## What's Working

- End-tournament sheet adapts copy and actions to the state and states each consequence.
- State survives reload mid-match, on the winner screen and between matches; locked screens ignore Escape.
- At 200% text on 320px the menu, setup, next-match and end sheets reflow with no clipped actions.

## Priority Issues

1. [P1] Tournament state is invisible on the board. Header adds only "Tabla"; nothing marks a tie-break once the undo bar is gone; "Terminar torneo" only via Tabla; reset sheet hint is plain text. Fix: a one-line strip under the header ("Primero a 2 · Partida 3" / "Desempate") that opens the table; make the reset sheet hint a button. Files: src/app/components/target-header.ts, src/app/app.html, src/app/components/reset-sheet.ts, src/app/copy.ts. Command: /impeccable layout
2. [P1] "Mejor de N" is labelled as matches but ends on wins. 4 teams, "Mejor de 3", three different winners: a 4th match opened. The majority rule was the user's decision; the label "Partidas en total" contradicts it. Fix: relabel to state wins, or offer "Mejor de" only with 2 teams. Files: src/app/components/tournament-setup-screen.ts, src/app/copy.ts, src/app/game/tournament.ts. Command: /impeccable clarify
3. [P2] Setup work is lost on Back. Escape on "Torneo nuevo" discards added teams; "Volver atrás" from the first match lands on the board with the list gone. Fix: keep the draft until a tournament starts; reopen setup with it. Files: src/app/components/tournament-setup-screen.ts, next-match-screen.ts, src/app/game/game.store.ts. Command: /impeccable harden
4. [P2] Names shrink to unreadable sizes. 16-character names at 320px: players line 6.5px (lockup, ranking), 6.8px (picker), 9.3px (seat, setup row); team name 7.8-10px. Fix: floor of about 12px in appFitText, then wrap the pair onto two lines. Files: src/app/directives/fit-text.ts, ranking-list.ts, next-match-screen.ts, team-lockup.ts. Command: /impeccable typeset
5. [P2] Deleting is the loudest action on record screens. "Eliminar" is the only filled button at the thumb on Partida and Torneo records; "Borrar historial" acts on one tap; single deletes undo for 8s only. Fix: outlined danger on record screens; confirming sheet with the count for clear-all. Files: match-screen.ts, tournament-record-screen.ts, history-screen.ts, copy.ts. Command: /impeccable harden

## Minor Observations

- Verb agreement: "Los Tigres gana la partida".
- History newest first; tournament record matches oldest first.
- History entries have no affordance that they open.
- Table does not mark the two teams now playing.
- Tied teams show as positions 1 and 2.
- Next-match screen: initial focus in the footer, seats reached last.
- Champion colour follows the seat of the last win, so a team can be orange on its record and yellow in its matches.
- At 320px/200%: menu team slab label "Los Compadres" clipped (120 vs 108), match detail side name clipped (126 vs 86).
- Tab cycle passes through body once per loop in headless Chrome.

## Questions to Consider

3. Does the menu need nine controls in one sheet?
